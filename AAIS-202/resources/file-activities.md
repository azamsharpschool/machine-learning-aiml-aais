
# 📂 Python File Management Exercises

---

### 1️⃣

Create a program that:

* Writes the text `"Hello Python"` into a file called `hello.txt`
* Reopens the file and prints its contents

---

### 2️⃣

Ask the user to enter their favorite movie.
Append the movie name to a file called `movies.txt` without deleting previous entries.

---

### 3️⃣

Read a file called `notes.txt`.
Print how many lines are in the file.

---

### 4️⃣

Read a file called `numbers.txt` where each line contains a number.
Calculate and print the total sum.

---

### 5️⃣

Read a file called `article.txt` and count:

* Total number of words
* Total number of characters (excluding spaces)

---

### 6️⃣

Create a dictionary representing a student (name, age, grade).
Save it to `student.json`.
Then load the file and print the student's grade.

---

### 7️⃣

Create a JSON file called `employees.json` containing a list of employees (name, department, salary).
Write a program that prints only employees with salary greater than 70,000.

---

### 8️⃣

Load a JSON file called `tasks.json` that contains a list of tasks (id, title, completed).
Find a task by id and update its completed status.
Save the updated file.

---

### 9️⃣

Read a text file called `raw_data.txt`.
Remove all blank lines and save the cleaned result into `cleaned_data.txt`.

---

### 🔟

Create a program that:

* Catches file-related errors using try/except
* Writes error messages into `errors.txt`
* Also stores structured error data (timestamp and message) in `errors.json`
