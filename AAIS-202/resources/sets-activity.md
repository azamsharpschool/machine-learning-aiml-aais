
# In Class Activity

## Real Life Use of Sets

**Time:** 10 minutes
**Work style:** Individual or pairs
**Rules:** Use sets only. Do not use lists or tuples unless explicitly told.

---

## Scenario

You are working on a **school registration system**.
Each student can enroll in multiple clubs, but a student **cannot join the same club twice**.

Your job is to model and manage club membership using sets.

---

## Exercise 1: Create the Club Roster (2 minutes)

Create a set named `science_club` containing the following student names:

* Alex
* Jordan
* Taylor
* Alex

Print the set.

---

## Exercise 2: Add New Members (2 minutes)

A new student named `Morgan` joins the science club.

Add Morgan to the set.

Print the updated set.

---

## Exercise 3: Prevent Duplicate Enrollment (2 minutes)

A student named `Jordan` tries to join the science club again.

Add Jordan to the set.

Print the set and observe what happens.

---

## Exercise 4: Find Common Members (2 minutes)

Create another set named `math_club` with the following students:

* Jordan
* Casey
* Taylor

Write code to find students who are in **both** clubs.

Print the result.

---

## Exercise 5: Reflection (2 minutes)

Answer in one or two sentences:

> Why is a set a better choice than a list for tracking club membership?
