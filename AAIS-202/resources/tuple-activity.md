
# In Class Activity

## Real Life Use of Tuples

**Time:** 10 minutes
**Work style:** Individual or pairs
**Rules:** Use tuples only. Do not use lists.

---

## Scenario

You are working on a **flight booking system**. Certain pieces of information must never change once a ticket is issued.

Your task is to model this data safely using tuples.

---

## Exercise 1: Ticket Information (3 minutes)

Create a tuple named `ticket_info` that stores the following in this exact order:

1. Passenger name
2. Flight number
3. Seat number
4. Departure city
5. Destination city

Print the entire tuple.

---

## Exercise 2: Read Only Access (2 minutes)

Using indexing, print:

* The passenger name
* The seat number

Do not modify the tuple.

---

## Exercise 3: Simulate a System Bug (2 minutes)

A bug in the system tries to change the seat number after the ticket is issued.

Write one line of code that attempts to update the seat number in the tuple.

Observe what Python does.

---

## Exercise 4: Unpack for Clarity (2 minutes)

Unpack the `ticket_info` tuple into individual variables with meaningful names.

Print each variable on its own line.

---

## Exercise 5: Reflection (1 minute)

Answer in one sentence:

> Why is a tuple a better choice than a list for this problem?
