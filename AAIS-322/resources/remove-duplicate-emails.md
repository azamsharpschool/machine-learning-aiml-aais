# 📝 Activity – Remove Duplicate Emails from Email List

In this assignment, you will work with a file that contains a long list of email addresses. Some of the emails appear more than once, and we don’t want to send duplicate emails to the same customer.

Your task is to:

1. **Read the `emails.txt` file**.
2. **Remove all duplicate email addresses**.
3. **Save the cleaned list** into a new file called `duplicate-free-email-list.txt`.
