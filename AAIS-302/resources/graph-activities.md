### 🔹 **Activity 2: Create a Bar Chart**

**Objective:** Visualize categorical data.

**Dataset (DataFrame format):**

```python
import pandas as pd

data = {
    "Fruit": ["Apples", "Bananas", "Cherries", "Grapes"],
    "Quantity": [10, 15, 7, 12]
}

df = pd.DataFrame(data)
```

📝 **Instructions:**

* Plot a bar chart using the DataFrame.
* Add a title and axis labels.
* Change the bar color.

### 🔹 **Activity 3: Create a Scatter Plot**

**Objective:** Show relationships between two sets of data.

**Dataset (DataFrame format):**

```python

    "MilesDriven": [5, 10, 15, 20, 25],
    "FuelUsed": [0.5, 0.8, 1.2, 1.6, 2.1]
}

df = pd.DataFrame(data)
```

📝 **Instructions:**

* Plot a scatter plot of `MilesDriven` vs. `FuelUsed`.
* Add labels and a title.
* Customize marker shape and color.
